Funnel bei Tailscale freischalten


    

      So verbindest du Claude
      
    
        
  1. Diagnosemodus starten und die Adresse oben kopieren.
    2. 
        
  2. In Claude unter „Connectors“ einen benutzerdefinierten Connector mit dieser Adresse hinzufügen (Anmeldung: OAuth, Client automatisch registrieren).
    3. 
        
  3. Claude öffnet eine Seite mit einem Code. Hier unter „Verbindungsanfragen“ denselben Code erlauben.
    4. 
        
  4. Claude schlägt Aufträge vor. Jeden einzelnen unter „Freigaben“ prüfen und bestätigen.
    5. 
      

      
Die Claude-App und claude.ai erreichen den Pi nur über das öffentliche Internet; dafür muss Port 443 per Tailscale Funnel offen sein (Schalter oben oder von Hand). Claude Code auf einem Gerät in deinem Tailnet funktioniert ohne Funnel. Website, Login und Freigaben sind über Funnel nie erreichbar.

      
Solange Funnel offen ist, kann der Name dieser Website auf deinen Geräten zur öffentlichen Adresse auflösen; dann erscheint hier nur „Not found“. Für diesen Fall einmalig einen privaten Zugang über die Tailnet-IP einrichten (README-CLAUDE-MCP.md, Abschnitt „Privater Zugang“) und die Website unter http://<Tailnet-IP>:8790/ öffnen.

Was geht hier?
    
Eine echte Shell auf der MGU als root, wie per SSH: Pipes, Umleitungen, Schleifen, mehrzeilige Skripte und Schreibbefehle. Jeder Befehl läuft in einer neuen Shell; Verzeichniswechsel mit cd gelten nur innerhalb des Befehls. Interaktive Programme (z. B. vi, top) gehen nicht, top -b -n 1 schon.
