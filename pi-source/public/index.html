So verbindest du Claude
  1. Diagnosemodus starten und die Adresse oben kopieren.
  2. In Claude unter „Connectors“ einen benutzerdefinierten Connector mit dieser Adresse hinzufügen (Anmeldung: OAuth, Client automatisch registrieren).
  3. Claude öffnet eine Seite mit einem Code. Hier unter „Verbindungsanfragen“ denselben Code erlauben.
  4. Claude schlägt Aufträge vor. Jeden einzelnen unter „Freigaben“ prüfen und bestätigen.

Die Claude-App und claude.ai erreichen den Pi nur über das öffentliche Internet; dafür muss Port 443 per Tailscale Funnel offen sein (Schalter oben oder von Hand). Claude Code auf einem Gerät in deinem Tailnet funktioniert ohne Funnel. Website, Login und Freigaben sind über Funnel nie erreichbar.

Welche Befehle funktionieren?

Die aktuelle Verbindung ist keine freie SSH-Shell. Unterstützt werden einzelne Lesebefehle, etwa ls /etc/cinemo, cat /etc/cinemo/cinemo_options.xml, grep -niE "audio|CarPlay" /etc/cinemo/cinemo_options.xml und find /usr/lib/oap-mainapp dsp.

Schleifen, Pipes, Umleitungen und Schreibbefehle werden absichtlich nicht ausgeführt. Ein | innerhalb eines in Anführungszeichen stehenden Suchbegriffs ist erlaubt. Für vollständiges Root-SSH benötigst du weiterhin deine separate MGU-SSH-App.

Raspberry-Pi-Updates

Nur ZIP-Pakete mit einer geprüften BMW-AI-Herausgebersignatur können installiert werden. Vorher wird ein Backup erstellt; bei fehlgeschlagenem Health-Test erfolgt ein Rollback. Die Anmeldedaten, Chats und Fahrzeugkopplung werden nicht ersetzt.

Manuelle Prüfung startet einen GitHub-Abruf. Bei aktivierter Automatik werden neue signierte Versionen installiert.

Gespeicherte Einstellung wird beim Öffnen geladen.
